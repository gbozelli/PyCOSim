# deprecated

This directory stores older implementations that are no longer part of the active execution path.

## Purpose
These modules are retained for reference, comparison, and historical context. They include earlier versions of optical and communication blocks such as:
- optical fiber and PMD models,
- laser and photodiode components,
- receiver and transmitter variants,
- constellation and spectrum analysis helpers.

## Notes
The code here is not the main development target. It should be treated as legacy material unless a specific migration or comparison task requires it.
